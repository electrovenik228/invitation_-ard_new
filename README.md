# Приглашение на Кыз узатуу - Адинай & Болотбек

Сайт-приглашение на кыргызское свадебное событие "Кыз узатуу" (проводы невесты).

## Структура проекта

```
invitation/
├── index.html           # Главный HTML файл
├── css/
│   └── style.css        # Основные стили
├── js/
│   └── script.js        # JavaScript функционал
├── assets/
│   ├── images/          # Изображения (цветы, фоны, иконки)
│   ├── fonts/           # Подключаемые шрифты
│   └── music/           # Фоновая музыка
└── README.md            # Этот файл
```

## Функции

- ✅ Двуязычный интерфейс (Кыргызский / Русский)
- ✅ Отзывчивый дизайн (mobile-first)
- ✅ Плавная навигация между секциями
- ✅ Интерактивный конверт
- ✅ Таймер обратного отсчета
- ✅ Форма подтверждения присутствия (RSVP)
- ✅ Фоновая музыка
- ✅ Интеграция с 2ГИС для карты

## Запуск локально

1. Откройте `index.html` в браузере, или
2. Используйте простой веб-сервер:
   ```bash
   python -m http.server 8000
   # затем откройте http://localhost:8000
   ```
